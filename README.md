# Туманы Баровии — стол ведущего

Мобильная читалка подготовки и отдельная листалка Тарокка.

- `docs/tarokka.html`: 54 карты с иллюстрациями, дословные книжные значения, толкования общего расклада, отдельные авторские личные заготовки, заметки и черновик пяти карт.
- `docs/index.html`: от деревни Баровия до озера Тсер; книжные выдержки и отдельные решения кампании.
- `docs/today.html`: актуальная подготовка сессии после пятой, карточки, готовка, Реми и сводка технического чата Foundry.
- `docs/future.html`: ранние следы будущего и аналитические разборы дополнений. Новые варианты не считаются принятым лором.
- `scripts/build_session.py`: пересобрать две новые вкладки из рабочих Markdown. Исходные PDF/полный корпус дополнений на сайт не копируются. Заметки и прочитанные разделы каждой вкладки сохраняются отдельно.
- `scripts/build.py`: локальная сборка выбранных данных из файлов кампании. Требует Python, PyMuPDF и Pillow. Исходные книги не загружаются целиком.

Публикация GitHub Pages: ветка `main`, папка `/docs`.

Все 54 базовых значения независимо сверяются с самим PDF в `scripts/build.py`; при расхождении сборка останавливается. Публичный результат сверки — `docs/meaning-audit.json`. Личные тексты хранятся отдельно в `scripts/personal_tarokka.py`, метод и внешние источники — в `scripts/tarokka_guide.py`. Новая трактовка не должна подменять поле `meaning`.

Заметки, закладки, место чтения и расклад хранятся только в браузере устройства. Экспорт/импорт JSON переносит их на другое устройство. Это не чат и не серверная синхронизация: кнопку копирования используют для обсуждения в чате с помощником.

Для офлайн-чтения сначала открыть сайт онлайн и нажать «Сохранить для дороги». Данные браузера могут быть удалены системой; важные заметки экспортировать.

Материалы содержат спойлеры для ведущего. GitHub Pages — доступный по ссылке сайт, не приватный игровой журнал. `noindex` не является защитой доступа. Книги и рисунки принадлежат их правообладателям; здесь использованы выбранные фрагменты из предоставленных ведущим материалов с указанием источников.
